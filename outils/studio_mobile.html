Clés de l'assistant

Clé gratuite Groq (obligatoire) : console.groq.com/keys → « Create API Key ». Secours facultatifs quand Groq est saturé : Cerebras (cloud.cerebras.ai) et OpenRouter (openrouter.ai/keys). Les clés restent seulement sur ce téléphone.

Clé GitHub

La page a besoin d'une clé personnelle (« token ») pour parler à votre dépôt. Elle reste seulement dans ce navigateur, jamais dans le dépôt.

  1. Ouvrez github.com/settings/personal-access-tokens/new
  2. Nom : studio mobile · Expiration : 1 an
  3. Repository access : Only select repositories → sounsouni-studio
  4. Permissions → Repository : Issues : Read and write, Contents : Read-only, Actions : Read-only
  5. Generate token, copiez-la et collez-la ici.
